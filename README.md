# To Do

A private checklist app. One page, no accounts, no server. Your list is saved on the device you use it on.

## Put it on GitHub (private)

1. On GitHub, create a new repository and set it to Private.
2. Upload these files to the root of the repo: index.html, manifest.json, sw.js, icon.svg, README.md.

## Run it on your phone

GitHub Pages from a private repo needs a paid GitHub plan. If you have one, turn on Pages for the repo (Settings, Pages, deploy from the main branch) and open the link on your phone. Then use Share, Add to Home Screen.

If you do not have a paid plan, keep the repo private as your backup and host the same files somewhere free that can be password protected, or just open index.html from your device.

## Notes

- The list lives in the browser on each device. Use the Back up button to save a JSON copy and Restore to load it on another device.
- Edit the starting list in the seed() function inside index.html.
